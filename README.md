# Documentation
Your character and background design choices:
Since my last game had a space theme, I wanted to keep the colors from it. Instead of doing space this time, I got inspired by the backgrounds of games in the “90s”. My character is a hooded figure that stands out from the background. They kind of look like an astronaut but also like someone who could be in regular life. The background is a calm night sky, but the character is mysterious which can set my game up for my character to be an explorer. 

Which tools did you use and why:
I used the website “PixilArt” to make my character background and platform. This was because it was easy t use, and I’ve have used it before. They were also easy to import as assets in Unity as I just had to download them as PNG images. 

How you exported/imported assets into Unity:
As I said before, I made the pixel art first and downloaded it. For the background, I made sure every single pixel was covered so that the background could cover the whole screen. Then, the platforms and characters have transparent background because I didn’t want them to cover up the whole screen. I downloaded it as a PNG and then imported it into Unity, so that I could use it. 

Any challenges you faced and how you solved them:
I had challenges with layering the character and making sure everything was the right size. If I were to download it at a smaller size and then bring it into Unity, the quality would be horrible. After downloading it multiple times, I was able to figure out the perfect size. Then, when I would put my characters onto the background, it would go behind it. I played around for a while and figured out the I had to set it to “Move to View” to layer it properly.
